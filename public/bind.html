为什么需要 Cookie?
QQ 音乐的扫码登录接口封禁了我们的服务器 IP, 无法自动获取登录凭证。 请在浏览器登录 QQ 音乐后, 复制 Cookie 到下方输入框。Cookie 仅用于获取 VIP 歌曲播放地址, 不会存储到服务器。
步骤1: 打开 https://y.qq.com/ 并用 QQ/微信登录
步骤2: 登录后, 按 F12 打开开发者工具
步骤3: 切换到 Console (控制台) 标签
步骤4: 输入 copy(document.cookie) 并回车, 自动复制 cookie
步骤5: 粘贴到下方输入框

常见问题

QQ 音乐 Cookie 安全吗? 仅用于获取 VIP 歌曲播放地址, 不会保存到服务器, 5 分钟后自动删除。

QQ 音乐 Cookie 包含哪些字段? 主要需要 uin (QQ号) 和 qqmusic_key (登录凭证), 复制 document.cookie 即可。

网易云验证码安全吗? 验证码仅用于本次登录请求, 服务端不保存, 登录成功后只保留返回的 Cookie 凭证。

网易云收不到验证码? 可能是机房 IP 被风控, 请改用 "Cookie 粘贴" 方式: 浏览器登录 music.163.com → F12 → Application → Cookies → 复制 MUSIC_U 值。

为什么不用扫码登录? 服务器在机房, 网易云会检测到"设备环境异常"并拦截扫码, 因此使用验证码或 Cookie 粘贴登录。

网易云验证码登录失败? 可能是机房 IP 被风控, 请改用 "Cookie 粘贴" 方式: 浏览器登录 music.163.com → F12 → Application → Cookies → 复制 MUSIC_U 值。

网易云 Cookie 怎么获取? 浏览器登录网易云后按 F12 → Application(应用) → Cookies → music.163.com → 找到 MUSIC_U 行复制其值, 或在 Network 标签任意请求的 Request Headers 里复制整段 Cookie。

绑定码过期了? 5分钟内有效, 过期请重新登录。

提示"已绑定"? 在游戏内先解绑, 再重新绑定。
