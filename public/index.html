简介

本服务为 Ourcraft 项目提供统一的音乐接口, 同时可作为独立 API 服务于以下客户端:

MetingJS Minecraft ZMusicGUI Node.js 应用 其他 HTTP 客户端

所有接口通过 /api 入口, 兼容 MetingJS 格式, 可直接用于 APlayer / MetingJS 播放器.

API 用法示例

# MetingJS 兼容格式 (默认)
GET /api?server=netease&type=url&id=174944
GET /api?server=netease&type=search&id=周杰伦&limit=10
GET /api?server=netease&type=playlist&id=60198&limit=100
GET /api?server=qq&type=song&id=0039MnYb0qxYhV

# JSON 输出 (非 302 跳转)
GET /api?server=netease&type=url&id=174944&json=1

# 健康检查
GET /api?action=health

# 多平台 (server 参数)
# netease | qq | kugou | kuwo
